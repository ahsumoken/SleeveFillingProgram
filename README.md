# Sleeve Tracker

PWA voor een 13-weken schema (start **21 september 2026**).

## Schema
- **Ma:** hardlopen + Arms Thuis 1
- **Di:** Arms Thuis 2
- **Wo:** hardlopen + KB Circuit A
- **Do:** Arms Thuis 3
- **Vr:** hardlopen + Plyo Box HIIT
- **Za:** Arms Thuis 4
- **Zo:** wandelen

Hardlopen: 5 km, elke 4e loopsessie 10 km. Totaal **240 km**.

## Materiaal
Optrekstang, plyobox, Nike DB tot 26 kg, KB 12/16/20, parallettes.

Geen weighted pull-ups; wel negatieven.

## Wijzigingen t.o.v. bron-sessies
1. Arms 1: negatieve chin-up 4×5-6, 5s zakken + 2s hold kin boven stang
2. Arms 2: kickback → Parallettes Triceps Extension 4×12-15
3. Arms 3: 21s curl → 21s Overhead DB Ext. 3×21
4. Arms 4: rear delt → Spider Curl DB 3×12-15
5. KB A finisher: geen ab wheel; Negatieve Pull-ups + Parallettes Knee Raise
